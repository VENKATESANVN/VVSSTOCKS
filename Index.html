How It Works

Four easy steps.

Select stocks

Use NIFTY 50, BANK NIFTY or F&O buttons, or search by code or company.

Choose the period

Pick From and To month, or use YTD, 6M, 12M, 24M.

Load data

Press LOAD DATA for month-wise or day-wise tables and the heatmap.

Customise and export

Arrange columns, then download CSV or Excel.

Run it yourself

Save your Python file as app.py, then run pip install streamlit yfinance pandas requests openpyxl and streamlit run app.py. To go live free, push to GitHub and deploy on Streamlit Community Cloud, then paste the app link into APP_URL in this page.
